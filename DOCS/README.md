**R. D. Cowan's own documentation** is in [`Cowan/`](Cowan/), copied
from his directory at LANL in December 1994 and preserved unaltered:
[RCN_DOC.txt](Cowan/RCN_DOC.txt) (RCN, RCN2 and HF8),
[RCG_DOC.txt](Cowan/RCG_DOC.txt), [RCE_DOC.txt](Cowan/RCE_DOC.txt), and
[readme.cowan.htm](Cowan/readme.cowan.htm), his write-up for his own
version of the package. Read them together with
[MANUAL_ADDITIONS.md](MANUAL_ADDITIONS.md).

Elsewhere in the package:

- each worked example in `WORK/` has a `README.txt` of its own;
- `FOR/LSJJ/README.txt` is the long-form development record -- the true
  *jj* coupling, the port of the utilities to Python, the port to Linux
  and macOS, the constants work -- with the measurements behind each
  change;
- the docstring at the top of each `.py` file in `CODE/` is the full
  description of that program.
